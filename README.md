# TLAQI Waitlist Landing Page

Arabic, RTL landing page built with Next.js, React, and Tailwind CSS. Includes the complete responsive design, animated university logos, brand assets, app icons, and signup preview with confetti.

This repository contains the frontend only. No database, Supabase client, credentials, or environment files are included. The signup form is a clearly labeled preview: email addresses are not sent or saved, and submission does not register a user.

## Run locally

```sh
npm ci
npm run dev
```

Open http://localhost:3000. No environment variables are required.

## Check and build

```sh
npm run lint
npm run build
npm start
```

Deploy as a Next.js project on a compatible hosting service. Connect a signup backend before enabling real waitlist registration.
